# Git & GitHub Final Project — IBM Front-End Developer Certificate

Ce dépôt est le projet final du cours **[Getting Started with Git and GitHub](https://www.coursera.org/learn/getting-started-with-git-and-github)** (IBM), dans le cadre du **IBM Front-End Developer Professional Certificate**.

## 📋 Contenu

- `README.md` — ce fichier de présentation
- `LICENSE` — licence open source MIT
- `notes/` — notes d'apprentissage sur Git et GitHub

## 🎯 Ce que ce projet démontre

- Création et gestion d'un dépôt GitHub public
- Rattachement d'une licence open source (MIT)
- Versionnement avec Git : commits, branches, push/pull
- Partage d'un projet open source

## 🚀 Utilisation

Clonez le dépôt :

```bash
git clone https://github.com/MaryseGAHOU/git-and-github-final-project.git
```
